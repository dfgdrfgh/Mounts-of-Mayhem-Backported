# Mounts of Mayhem recovery

The current release branch was missing the changes from closed, unmerged PR #1.
This recovery merges its last head, `1d1e246cb2be3a5165a2b8a4911a32ccc0aab78d`,
with `3874cf38c92d536700b6ef6621d9f15ab0585cb3`. Both histories are retained.

Restored content includes Netherite Horse Armor; Nautilus, Zombie Nautilus and
the coral variant; all five Nautilus armor tiers; Breath of the Nautilus;
inventories, rendering, sounds, spawning, loot, recipes and advancements; and
the earlier spear, Lunge, Camel Husk, Parched and Zombie Horse parity changes.

## Instructions preserved

- Target: Mounts of Mayhem content from Java 1.21.11 on Java 1.21.1.
- Keep the recovered branch's scope exclusions, including Copper Horse Armor
  and unrelated bat/graphics changes. Copper Nautilus Armor and Copper Spears
  are part of Mounts of Mayhem and remain included.
- Keep loader ID `mombackport`, display name `MoM Backport`, configuration name
  `mombackport` and JAR prefix `MoMBackport` from the current release branch.
- Keep the exact approved icon, byte-for-byte, at `assets/barched/icon.png`.
  Both loader metadata files point to that same image.
- Retain the repaired Camel Husk spawn-egg model and texture.
- Preserve the existing internal Java/resource layout from the current branch.

## Recovery fixes and validation

Architectury's Fabric spawn wrapper does not implement `getSpawners()`. The
recovered branch called it for both Zombie Horse and Parched spawn-weight
adjustments. Both now use the supported removal callback, collect matching
entries, then add adjusted entries after iteration. Group sizes and unrelated
entries are preserved. Focused JUnit regressions cover both adjustments, empty
biomes, exhausted weights, multiple entries and mutation during iteration.

The existing Zombie Nautilus variant codec tests are restored. The build now
also checks both release JARs for recovered classes, item models, armor textures,
recipes, variants, registered mixins, valid JSON/PNG resources, and the exact
source icon. This prevents another successful build silently omitting the
recovered content.

References checked for scope:
- https://modrinth.com/mod/vanillabackport
- https://minecraft.wiki/w/Mounts_of_Mayhem (access blocked in this environment)
- https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11

Build and resource checks do not establish complete in-game 1:1 parity. World
startup with the user's modpack, riding/equipment interactions, save/reload and
multiplayer synchronization still require gameplay testing. Earlier detailed
source comparisons and their limits remain in `parity-audit-2026-09-29.md`.
